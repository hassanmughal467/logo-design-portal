# Logo Design Portal

A full-stack web application for managing logo design orders, clients, and designer workflows.

**Stack:** Angular (frontend) · ASP.NET Core (backend) · SQL Server

## Quick Start

```bash
# Terminal 1 — Backend
cd Backend/src/LogoDesignPortal.API
dotnet run
# Runs on http://localhost:5000
```

```bash
# Terminal 2 — Frontend
cd Frontend
npm install   # first time only
npm start
# Runs on http://localhost:4200
```

Open `http://localhost:4200` and log in with `superadmin@logodesign.com` / `SuperAdmin@123`.
